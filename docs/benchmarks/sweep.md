# Random-input accuracy sweep

Generated by `make sweep` (`scripts/sweep/sweep.py`, `test/sweep/Sweep.t.sol`) from seeded random inputs. FP256 is compared with the correctly rounded word (scripts/fp256/oracle.py, 300 digits, ties away from zero); FP127 with the real truth at 200 digits, in units of 2^-128. Data: `sweep.json`.

## FP256

Release four: every op below is correctly rounded or exact by construction; the directed ops (Down: toward minus infinity, Up: toward plus infinity) are compared with the exact value rounded in their direction, the plain-integer ones (toUint, toInt) as integers.

Gas is the inline library's (FP256Lib) own cost on these inputs, median / 99th percentile / largest, the second stage's runs included where the fast value's error bound reached the rounding boundary.
