Bits are relative correct bits of the result on the decoded values: the significands aligned at the larger exponent, msb(truth) - msb(|truth - got|). "exact" means bit-identical, or within 2 ULP for an approximated op. `reverts` counts vectors where the oracle and the Yul both reject the input with the same error.
