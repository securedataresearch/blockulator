Bits are relative correct bits of the result on the decoded values: the significands aligned at the larger exponent, msb(truth) - msb(|truth - got|). "exact" means bit-identical: since release four every FP256 op returns the oracle's word (correctly rounded, ties away from zero; the Down and Up ops rounded toward minus or plus infinity). `reverts` counts vectors where the oracle and the Yul both reject the input with the same error.
