Release one (2026-10-15): 19 ops; add, sub, mul, div, sqrt, the comparisons
and the conversions exact to the 237-bit grid; exp, ln and pow on FP127's
2^-192 kernels (146, 149 and 123 bits at worst over the vectors).

## Reproduce the bytecode

```sh
make build
FP_LIB=fp256 uv run scripts/fp127/stdjson.py check   # solc standard-json (language Yul) == Foundry artifact
make predict-fp256                                   # the address above, from the artifact alone
FP_LIB=fp256 uv run scripts/fp127/stdjson.py onchain https://ethereum-sepolia-rpc.publicnode.com 0x628b8dfC82954983a9E8E22056ffc767B4a26077
```
