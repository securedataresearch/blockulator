Release four (2026-10-21): 67 ops, every one correctly rounded or exact, 0
misrounded of 364,658 random inputs (`docs/benchmarks/sweep.md`). A fast
value whose stated error bound reaches the rounding boundary is recomputed
in two words at 2^-510; pow, powu and compound compute exact ties exactly.
It adds the edge (`mulDown`, `mulUp`, `divDown`, `divUp`, `toUintDown`,
`toUintUp`, `toIntDown`, `toIntUp`, `toFixed18Down`, `toFixed18Up`,
`floor`, `ceil`, `fromUintDown`, `fromUintUp`) and every op FP127 has.
FP256 holds the arithmetic, the edge, exp, ln, log1p, expm1, pow, powu,
compound, the comparisons and the conversions; FP256X erf, erfc, normCdf
and both Lambert branches; FP256X2 exp2, exp10, log2, log10, log2Up, cbrt
and the hyperbolics; FP256X3 the algebraic ops. See
`contracts/src/fp256/README.md` and `CHANGELOG.md`. Releases one to three
stay deployed and verified and are recorded below; the ladder's version 9
`LadderFP256` inlines release four.

## Reproduce the bytecode

```sh
make build
FP_LIB=fp256 uv run scripts/fp127/stdjson.py check   # solc standard-json (language Yul) == Foundry artifact
make predict-fp256                                   # the FP256 address above, from the artifact alone
make predict-fp256x predict-fp256x2 predict-fp256x3   # the other three
FP_LIB=fp256 uv run scripts/fp127/stdjson.py onchain https://ethereum-sepolia-rpc.publicnode.com 0xA3C8C8700465F9e20Ff9dfA64066c2EF693Aa6c9
```
