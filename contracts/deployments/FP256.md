Release three (2026-10-16): 28 ops, adding log1p, expm1, erf, erfc, normCdf,
lambertW0, lambertWm1, powu and compound. exp, ln, log1p, expm1, erf, erfc,
normCdf and every non-transcendental op equal the oracle's word at every
committed vector; pow, powu and compound are within one unit in the last
place where |y log2 x| < 2^13; the Lambert branches are within one unit away
from -1/e. Runtime 24,299 of the 24,576-byte limit.

## Reproduce the bytecode

```sh
make build
FP_LIB=fp256 uv run scripts/fp127/stdjson.py check   # solc standard-json (language Yul) == Foundry artifact
make predict-fp256                                   # the address above, from the artifact alone
FP_LIB=fp256 uv run scripts/fp127/stdjson.py onchain https://ethereum-sepolia-rpc.publicnode.com 0x67eFfb11bF93c79a2B12cc7872cBaC12b3eB61be
```
